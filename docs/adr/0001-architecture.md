# ADR 0001: Architecture

Status: Accepted. Date: 2026-11-24.

## Context
The prototype (`chatbot-az-autogen`) had one global conversation for all users, no auth with a hardcoded
identity, an in-memory fake database, `asyncio.run()` inside a Flask-SocketIO handler, agents rebuilt on
every message, hardcoded URLs and GUIDs, `requests` calls without timeouts, unescaped HTML output, and
no tests, logging or CI. We are replacing it, not porting it.

## Decisions
1. **Stateless API processes.** FastAPI (async) with no process-level mutable state. Anything shared
   lives in Redis (session state, rate limits, budgets, upstream chat id) or Postgres (durable data).
2. **Identity from the token only.** Every HTTP/SSE request validates an Entra ID JWT (issuer, audience,
   signature via cached JWKS, expiry). `user_id` is never read from prompt, body or agent memory. A
   separate LOCAL_DEV auth mode uses a signed test token and refuses to start when
   `ENVIRONMENT=production`.
3. **Authorization in the data layer.** Every repository query takes `user_id` and filters on it. "Not
   yours" and "does not exist" return the same not-found result.
4. **Two assistants, deterministic router.** A rule-based intent router picks the Policy or Product
   assistant; the UI can override. No LLM call is spent on routing.
5. **Agents.** The Azure OpenAI model client is built once at startup. Agents are built per request by a
   factory; AutoGen team state is loaded from and saved to the Redis session store (key
   `user_id:session_id`, TTL). Limits: max turns, max tool calls, hard request timeout, safe fallback
   message; no stack traces reach the client.
6. **Tools are thin.** Typed pydantic arguments, structured JSON results, each wrapping a service in
   `app/services`. Descriptions state when to call, never "always call".
7. **Outbound calls.** One shared `httpx.AsyncClient`, connect/read timeouts, tenacity retries (3, jittered
   backoff, 5xx and timeouts only), circuit breaker. Upstream chat id cached per session.
8. **Documents.** PDFs are generated by an arq worker on Redis, stored in Blob Storage, and served via
   short-lived read-only SAS URLs scoped to one blob.
9. **Persistence.** Postgres via SQLAlchemy 2 async + asyncpg, schema managed by Alembic. Tables: users,
   policies, claims, documents, conversations, messages, audit_log.
10. **Config and secrets.** pydantic-settings only. Key Vault in Azure, `.env` in local dev only.
11. **Observability.** structlog JSON with PII redaction; OpenTelemetry traces and metrics to Azure
    Monitor; `/healthz` and `/readyz`.
12. **Frontend.** Vite + React + TypeScript, SSE streaming, text-node rendering only (no innerHTML).
13. **Delivery.** Multi-stage non-root Docker image, Bicep for Azure Container Apps and dependencies,
    GitHub Actions CI with an 85% coverage gate on `app/`.

## Consequences
- Horizontal scaling is trivial; Redis and Postgres become hard dependencies (reflected in `/readyz`).
- Deterministic routing is less flexible than LLM routing; misroutes are mitigated by the UI override
  and the eval suite.
- Tool-level scoping plus repository-level scoping means a prompt-injected agent still cannot read
  other users' data.
